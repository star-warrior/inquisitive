# Project: Inquisitive

## Vision
Inquisitive is an AI-driven learning platform designed to enrich and organize user learning materials through an interactive Kanban board.

## Objectives
- High-fidelity visual interface and premium user experience.
- Scalable, robust backend architectures.
- Secure, high-performance infrastructure including robust rate limiting.

## Validated Requirements
- **REQ-SEC-01, REQ-SEC-02, REQ-SEC-03, REQ-SEC-04** (Validated in Phase 1: Redis and IP-based Rate Limiting Refactor on 2026-05-28)

## Current State
- **Phase 1 Complete:** Redis-backed rate limiting with client IP tracking and fail-open survivability fully implemented and verified in the backend.
