  <action>
    Create a pure TypeScript utility module at `frontend/src/lib/streak.ts`.
    Define StreakState interface:
    ```typescript
    export interface StreakState {
      currentStreak: number;
      lastActiveDate: string; // YYYY-MM-DD
      longestStreak: number;
    }
    ```
    Implement:
    1. `getLocalDateString()`: Constructs YYYY-MM-DD from the user's local timezone dates (e.g. using local year, month, date components).
    2. `getStreakState()`: Reads `"inquisitive_streak"` from localStorage, parses JSON, handles errors, and returns a valid fallback state if corrupt or empty.
    3. `setStreakState(state)`: Stringifies and saves state to localStorage safely.
    4. `calculateStreakUpdate(currentState, todayDateStr)`: Pure calculation of the next streak state.
       - If currentStreak is 0, return streak = 1, lastActiveDate = today, longestStreak = 1.
       - If lastActiveDate is today, return currentState (no-op).
       - Check day difference between lastActiveDate and today.
       - If diff is exactly 1 day, increment streak, update longestStreak, update lastActiveDate.
       - If diff is > 1 day, reset streak to 1, update longestStreak, update lastActiveDate.
       - If diff is < 0 (clock change), return currentState (no-op).
  </action>
