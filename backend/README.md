# 🚀 Inquisitive Backend Service

This is the Express API microservice backend for Inquisitive.

## Tech Stack
- **Express.js** — Lightweight server router
- **Morgan** — Dev HTTP logger
- **Neon Serverless Postgres** — Cloud Postgres database
- **Drizzle ORM** — Modern Type-safe ORM
