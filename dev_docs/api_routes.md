# Inquisitive API Reference

This document outlines all available API routes, request/response formats, headers, and error handling for the Inquisitive backend server.

- **Base URL**: `http://localhost:3000` (Default)
- **Common Headers**:
  - `useruuid`: Required for most notebook routes to identify the user/device.

---

## Endpoint Summary

### Notebook Management (`/api/notebook`)

| Method   | Path           | Description                               | Authentication / Headers |
| -------- | -------------- | ----------------------------------------- | ------------------------ |
| `GET`    | `/getAll`      | Fetch all notebooks for a user            | `useruuid` (Header)      |
| `POST`   | `/create`      | Create a new notebook with AI resources   | `useruuid` (Header)      |
| `DELETE` | `/:notebookId` | Delete a notebook (cascades to resources) | `useruuid` (Header)      |

### Resource Management (`/api/resources`)

| Method   | Path                  | Description                               | Authentication / Headers |
| -------- | --------------------- | ----------------------------------------- | ------------------------ |
| `GET`    | `/:notebookId`        | Get all resources for a specific notebook | None                     |
| `PATCH`  | `/update/:resourceId` | Update the status of a specific resource  | None                     |
| `DELETE` | `/:resourceId`        | Delete a specific resource                | None                     |

### AI Orchestrator (`/api/ai`)

| Method | Path      | Description                                | Authentication / Headers |
| ------ | --------- | ------------------------------------------ | ------------------------ |
| `POST` | `/search` | Query the AI to build a plan (no DB write) | None                     |

### System & Health

| Method | Path      | Description         | Authentication / Headers |
| ------ | --------- | ------------------- | ------------------------ |
| `GET`  | `/health` | Server health check | None                     |

## 1. System & Health

### Health Check

Verify the server status and connection health.

- **Endpoint**: `/health`
- **Method**: `GET`
- **Request**: None
- **Response (200 OK)**:
  ```json
  {
    "status": "OK",
    "message": "Inquisitive API server is online."
  }
  ```

## 2. Notebook Management (`/api/notebook`)

### Get All Notebooks

Fetches all notebooks generated by the current device/user.

- **Endpoint**: `/api/notebook/getAll`
- **Method**: `GET`
- **Headers**:
  - `useruuid`: `string` (Required, unique device/user UUID)
- **Response (200 OK)**:
  ```json
  [
    {
      "id": "e5c704f0-4fa4-46ab-85fa-7c40d2ee8a6b",
      "deviceId": "c88085d9-31ff-48b2-b43e-c6a6fbb8d641",
      "createdAt": "2026-05-27T10:00:00.000Z",
      "topic": "Rust Concurrency",
      "level": "intermediate",
      "length": "medium"
    }
  ]
  ```
- **Response (400 Bad Request / 500 Error)**:
  ```json
  "No Id of the user provided"
  ```
  ```json
  "Invalid useruuid provided"
  ```

### Create Notebook

Requests the AI orchestrator to build a curated learning plan, saves the notebook record, and populates the database with learning resources.

> [!NOTE]
> Database operations are sequenced so that the notebook and its resources are only saved in the database once the AI has successfully generated the resources, ensuring no partial or corrupted notebooks exist.

- **Endpoint**: `/api/notebook/create`
- **Method**: `POST`
- **Headers**:
  - `useruuid`: `string` (Required, unique device/user UUID)
- **Request Body**:

  ```json
  {
    "topic": "Rust Concurrency",
    "level": "intermediate",
    "length": "medium"
  }
  ```

  _Field Specifications:_
  - `topic`: `string` (The subject to learn)
  - `level`: `"beginner" | "intermediate" | "hard"`
  - `length`: `"short" | "medium" | "long"`

- **Response (200 OK)**:

  ```json
  {
    "success": true,
    "data": {
      "notebook": {
        "id": "e5c704f0-4fa4-46ab-85fa-7c40d2ee8a6b",
        "deviceId": "c88085d9-31ff-48b2-b43e-c6a6fbb8d641",
        "createdAt": "2026-05-27T10:00:00.000Z",
        "topic": "Rust Concurrency",
        "level": "intermediate",
        "length": "medium"
      },
      "resources": [
        {
          "id": "3b29c9df-2df5-4ca9-adbb-11a5fe04e2ad",
          "notebookId": "e5c704f0-4fa4-46ab-85fa-7c40d2ee8a6b",
          "title": "Introduction to Rust Threads",
          "url": "https://example.com/rust-threads",
          "thumbNail": "https://example.com/thumbnail.png",
          "sourceType": "article",
          "difficulty": "2",
          "status": "todo",
          "summary": "Learn the basics of spawning native threads in Rust...",
          "createdAt": "2026-05-27T10:00:01.000Z",
          "updatedAt": "2026-05-27T10:00:01.000Z"
        }
      ]
    }
  }
  ```

- **Error Responses**:
  - **400 Bad Request (Missing/Invalid useruuid)**:
    ```json
    {
      "success": false,
      "message": "Invalid useruuid provided"
    }
    ```
  - **400 Bad Request (Invalid/Off-topic query)**:
    ```json
    {
      "success": false,
      "errorType": "INVALID_TOPIC",
      "reason": "off_topic",
      "message": "The query is not suitable for notebook generation."
    }
    ```
  - **422 Unprocessable Entity (No Search Results Found)**:
    ```json
    {
      "success": false,
      "errorType": "NO_SEARCH_RESULTS",
      "message": "No relevant learning materials or tutorials could be found for this topic. Please try a different or more specific topic."
    }
    ```
  - **502 Bad Gateway (AI Service Parsing Failures)**:
    ```json
    {
      "success": false,
      "errorType": "AI_SERVICE_ERROR",
      "message": "Failed to parse structured response from the LLM."
    }
    ```
  - **503 Service Unavailable (API Quota/Rate Limit)**:
    ```json
    {
      "success": false,
      "errorType": "MODEL_EXHAUSTED",
      "message": "Our AI systems are experiencing heavy traffic and models are currently exhausted. Please try again in a few moments."
    }
    ```

### Delete Notebook

Deletes a specific notebook by its ID, provided it belongs to the authenticated user.

> [!IMPORTANT]
> Because of database cascading rules configured on the foreign keys, deleting a notebook **automatically deletes all corresponding resource records** belonging to it from the database.

- **Endpoint**: `/api/notebook/:notebookId`
- **Method**: `DELETE`
- **Headers**:
  - `useruuid`: `string` (Required, unique device/user UUID)
- **Path Parameters**:
  - `notebookId`: `string (UUID)` (The ID of the notebook to delete)

- **Response (200 OK)**:

  ```json
  {
    "success": true,
    "message": "Notebook deleted successfully",
    "data": {
      "id": "e5c704f0-4fa4-46ab-85fa-7c40d2ee8a6b",
      "deviceId": "c88085d9-31ff-48b2-b43e-c6a6fbb8d641",
      "createdAt": "2026-05-27T10:00:00.000Z",
      "topic": "Rust Concurrency",
      "level": "intermediate",
      "length": "medium"
    }
  }
  ```

- **Error Responses**:
  - **400 Bad Request (Missing/Invalid credentials or parameters)**:
    ```json
    {
      "success": false,
      "message": "Invalid notebookId provided"
    }
    ```
  - **404 Not Found (Unauthorized or Notebook does not exist)**:
    ```json
    {
      "success": false,
      "message": "Notebook not found or unauthorized to delete"
    }
    ```

### Update Resource Status

Updates the tracking status of a single learning resource (e.g., marks it as skipped or completed).

- **Endpoint**: `/api/resources/update/:resourceId`
- **Method**: `PATCH`
- **Path Parameters**:
  - `resourceId`: `string (UUID)` (The specific resource ID to modify)
- **Request Body**:

  ```json
  {
    "status": "completed"
  }
  ```

  _Field Specifications:_
  - `status`: `"todo" | "in_progress" | "completed" | "skipped"` (Required enum string)

- **Response (200 OK)**:

  ```json
  {
    "success": true,
    "data": {
      "id": "3b29c9df-2df5-4ca9-adbb-11a5fe04e2ad",
      "notebookId": "e5c704f0-4fa4-46ab-85fa-7c40d2ee8a6b",
      "title": "Introduction to Rust Threads",
      "url": "https://example.com/rust-threads",
      "thumbNail": "https://example.com/thumbnail.png",
      "sourceType": "article",
      "difficulty": "2",
      "status": "completed",
      "summary": "Learn the basics of spawning native threads in Rust...",
      "createdAt": "2026-05-27T10:00:01.000Z",
      "updatedAt": "2026-05-27T15:30:00.000Z"
    }
  }
  ```

- **Error Responses**:
  - **400 Bad Request (Invalid Resource ID format)**:
    ```json
    {
      "success": false,
      "message": "Invalid resourceId provided"
    }
    ```
  - **400 Bad Request (Invalid Status Enum value)**:
    ```json
    {
      "success": false,
      "message": "Invalid status provided. Must be one of: todo, in_progress, completed, skipped"
    }
    ```
  - **404 Not Found (Resource does not exist)**:
    ```json
    {
      "success": false,
      "message": "Resource not found"
    }
    ```

## 4. AI Orchestrator (`/api/ai`)

### Dry Run AI Search

Run the full AI orchestrator pipeline to retrieve curated online tutorial/article links and learning paths.

> [!NOTE]
> Unlike `POST /api/notebook/create`, this is a read-only endpoint that generates suggestions but **does not create any database records**.

- **Endpoint**: `/api/ai/search`
- **Method**: `POST`
- **Request Body**:

  ```json
  {
    "topic": "Rust Concurrency",
    "level": "intermediate",
    "length": "medium"
  }
  ```

  _Field Specifications:_
  - `topic`: `string`
  - `level`: `"beginner" | "intermediate" | "hard"`
  - `length`: `"short" | "medium" | "long"`

- **Response (200 OK)**:

  ```json
  {
    "success": true,
    "result": {
      "topic": "Rust Concurrency",
      "level": "intermediate",
      "length": "medium",
      "resources": [
        {
          "title": "Introduction to Rust Threads",
          "url": "https://example.com/rust-threads",
          "thumbnail": "https://example.com/thumbnail.png",
          "source_type": "article",
          "difficulty": 2,
          "status": "todo",
          "summary": "Learn the basics of spawning native threads in Rust...",
          "position": 1
        }
      ]
    }
  }
  ```

- **Error Responses**:
  Identical in type and format to the AI search failure responses detailed in the **Create Notebook** section (e.g., `INVALID_TOPIC` (400), `NO_SEARCH_RESULTS` (422), `AI_SERVICE_ERROR` (502), and `MODEL_EXHAUSTED` (503)).
